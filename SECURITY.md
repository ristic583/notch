# Security

If you find a security problem in Notch, please report it privately: open this repository's **Security** tab and choose **Report a vulnerability**. That reaches the maintainer without making the details public.

Please don't open a public issue for it.

Worth reporting, among other things:

- anything that lets another app or a web page make Notch run code, read your clipboard history or change `~/.claude/settings.json`;
- anything that sends data off your Mac that the README doesn't mention;
- a way to get an update installed that the maintainer didn't sign.
